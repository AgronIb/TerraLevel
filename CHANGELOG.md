# Changelog

## 0.1.0 (2026-10-09)

First release. Built for Valheim 1.0.17.

- New hoe mode **Level Ground (TerraLevel)**: levels the terrain in a disc to the ground height under the cursor in one click, with no ±8 m height limit.
- Radius adjustable in-game: hold Left Ctrl (configurable) and scroll. Ring on the placement ghost shows the current radius.
- Vanilla Level Ground / Raise Ground untouched by default; `UnlimitedForVanillaTools` lifts their cap too.
- Height limit, radius limit and smoothing are server-synced admin settings.
